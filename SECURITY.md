# Security Policy

StateBreak is a local test harness, not a production security boundary. Do not run untrusted adapters in a privileged environment. The default package does not contact the network or process real credentials.

For a vulnerability in the package, report privately through the repository’s security advisory mechanism. Include a minimal reproduction, affected version, expected behavior, and whether the issue can escape the local fixture boundary. Do not publish secrets or exploit instructions in an issue.
